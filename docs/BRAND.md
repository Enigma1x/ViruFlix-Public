# Brand and UI guide

Canonical values live in `src/styles/variables.css` and the `@theme` block in `src/index.css`.

| Role | Token | Value |
| --- | --- | --- |
| Background | `--color-bg-primary` / `viru-dark` | `#0B0C10` |
| Panel | `--color-bg-secondary` / `viru-dark-alt` | `#111218` |
| Brand and CTA | `--color-brand-primary` / `viru-red` | `#E50914` |
| Accent and focus | `--color-brand-secondary` / `viru-cyan` | `#45F3FF` |
| Primary text | `--color-text-primary` | `#FFFFFF` |
| Secondary text | `--color-text-secondary` | `#B3B3B3` |

Use Bebas Neue for headings and Inter for body text. Prefer the shared `ViruButton`, form controls, and UI primitives before adding new components. Keep visible focus, keyboard access, useful image alt text, reduced-motion support, and WCAG AA contrast in new screens.
